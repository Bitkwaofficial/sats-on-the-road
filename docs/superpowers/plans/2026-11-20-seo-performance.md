# SEO and asset-size improvements

Scope: improve the existing site’s crawlability and delivery size; preserve the approved visual design, Nigeria form, contact addresses and payment destinations.

1. Measure source sizes and audit live routes, canonical URLs, robots and sitemap.
2. Generate smaller, content-hashed WebP images when smaller than their originals. Preserve originals and QR codes. Add intrinsic image dimensions.
3. Minify and fingerprint CSS/JS. Load fundraising scripts only on /fuel; defer ordered scripts.
4. Make error pages noindex; clean canonical-only sitemap without artificial modification dates or unsupported language alternates. Keep the French interface toggle.
5. Add a clear home-page link to Nigeria, descriptive titles and truthful organisation metadata.
6. Test generated links, crawl rules, build reproducibility, payload savings, page layout, translation and form interactions. Publish and verify live responses.

Google Search Console ownership access is needed to inspect actual indexing and submit the sitemap. Public crawl checks cannot establish index inclusion or guarantee rankings.
