# Sats On The Road Africa

Campaign site for **Sats On The Road Africa 2026** (BitKwa). Live at
**https://satsontheroad.africa**.

A grassroots Bitcoin road trip across Africa: teaching self-custody, Lightning
payments and real merchant adoption, country by country. The two-day field
curriculum taught on the trip lives in a separate repo,
[sats-on-the-road-curriculum](https://github.com/Bitkwaofficial/sats-on-the-road-curriculum).

## How it is built

A static multi-page site generated by a tiny Node build step, no framework.

- Source of truth is `src/` (`base.html` template, `partials/`, `sections/`,
  `pages/`, `pages.json` manifest).
- `node build.js` stitches those into the finished pages at the repo root
  (`index.html`, `mission.html`, `journey.html`, `movement.html`, `fuel.html`,
  `join.html`, `contact.html`, `privacy.html`, `terms.html`, `404.html`) plus
  `sitemap.xml`. `wall.html` and `wall-admin.html` are hand-maintained.
- To change a page: edit `src/`, run `node build.js`, then commit the regenerated
  HTML.
- `styles.css` and the page scripts (`app.js`, `i18n.js`, `price-ticker.js`,
  `converter.js`, `geyser.js`, `share.js`, `waitlist.js`, `wall*.js`) are served
  as-is. `assets/` holds images, the logo, gallery and partner logos.

## Serverless (`api/`, Vercel functions)

- `api/raised.js` proxies the Geyser fundraiser total.
- `api/wall/*` back the Wall of Support (Upstash Redis KV): submit, list, pending,
  moderate, approved.
- The waitlist at `/join` posts to a Google Apps Script that appends to a Google
  Sheet (script source in `google-apps-script/`).

## Local preview

Clean URLs mean you need a server that maps `/mission` to `mission.html`:

```bash
npx serve .
```

Opening the HTML files directly works for most pages; `/api/*` only runs on Vercel.

## Deploy

Hosted on Vercel (preset *Other*, no build command, the HTML is pre-built and
committed). Every push to `main` redeploys. Custom domain:
**satsontheroad.africa** (apex; `www` 308-redirects to the apex).

## Contact form

Submits via AJAX to Formspree (`app.js`). To change the destination inbox, update
the form `action` endpoint in the contact section and the fallback email in
`app.js`.
